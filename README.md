# Countdown Timer & Stopwatch

A responsive web app built with HTML, CSS and vanilla JavaScript.

## Features
- Countdown timer (hours / minutes / seconds) with presets, pause/resume, progress ring, sound alert
- Stopwatch with centisecond precision and lap table (best / worst lap highlighted)
- Light / Dark theme, mobile friendly

## Run locally
Open `index.html` in any browser. No build step or dependencies.

## Deploy on GitHub Pages
Settings → Pages → Source: `main` branch, `/ (root)` → your site goes live at
`https://<username>.github.io/<repo>/`
